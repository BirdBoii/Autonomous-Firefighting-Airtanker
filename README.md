# Autonomous Firefighting Airtanker

Controlling and path planning of a fixed wing waterbomber aircraft in MATLAB Simulink. 


## Control Dynamics-

The Model of the plane was fed into USAF DATCOM to get the stability derivatives. These constants were fed into MATLAB Simulink to model the aircraft. The model was based on the build in example, 'Lightweight Airplane Design' with appropriate changes made. A custom DATCOM input file was made for the project.
